# TCM-Acupuncture-Causal

**Causal Inference and Individualized Acupoint Recommendation for Acupuncture Therapy**

A computational framework for estimating heterogeneous treatment effects from acupuncture data, combining target trial emulation, uplift modeling, and association rule mining for evidence-based acupoint combination optimization.

## Overview

Acupuncture is a core therapeutic modality in traditional Chinese medicine, yet rigorous causal inference for its treatment effects remains challenging due to confounding, heterogeneity across patients, and the combinatorial nature of acupoint prescriptions. This project provides a principled statistical framework to address these challenges.

The system implements target trial emulation to reduce observational study biases, causal forest and uplift modeling to estimate individualized treatment effects (ITE/ATE), and association rule mining to discover acupoint pairing patterns from clinical prescriptions.

> **Important Disclaimer**
>
> **All data used in this project is synthetic (simulated).** The dataset
> generated by `scripts/generate_synthetic_acupuncture.py` and the experiment
> pipeline in `scripts/run_experiment.py` produce artificial data with
> programmatically defined treatment effects.  No real patient data is included,
> and any performance metrics (bias, RMSE, coverage) reported by the experiment
> scripts reflect synthetic-data evaluation only.  They **do not** represent
> clinical efficacy or real-world treatment outcomes.  This framework is
> intended as a methodological prototype; integration with real clinical
> datasets is listed in the roadmap and has not yet been carried out.

## Key Features

- **Target Trial Emulation** -- Applies the target trial framework to acupuncture observational data, defining eligibility criteria, treatment arms, and follow-up periods to reduce confounding
- **Causal Forest (T-Learner)** -- Estimates individualized treatment effects with bootstrap-based confidence intervals using separate Random Forest models for treated and control groups
- **Uplift Modeling** -- Two-model approach with gradient-boosted trees or Random Forests, including Qini curve evaluation for treatment targeting
- **Association Rule Mining** -- Discovers frequent acupoint combinations and co-prescription patterns from clinical prescription data
- **Protocol Management API** -- CRUD interface for defining and managing acupuncture trial protocols with configurable eligibility criteria and outcome measures

## Quick Start

### Prerequisites

- Python 3.10+

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/TCM-Acupuncture-Causal.git
cd TCM-Acupuncture-Causal

# Install in development mode
pip install -e .
```

### Run the Server

```bash
uvicorn backend.main:app --port 8020 --reload
```

The API documentation is available at `http://localhost:8020/docs`.

### Verify Installation

```bash
# Smoke test
python -c "from backend.main import app; print('Import OK')"

# Run tests
pytest backend/tests/ -v
```

### Example: Causal Effect Estimation

```bash
curl -X POST http://localhost:8020/analysis/causal-forest \
  -H "Content-Type: application/json" \
  -d '{
    "X": [[1,2],[3,4],[5,6],[7,8],[2,3],[4,5],[6,7],[8,9]],
    "treatment": [1,1,1,1,0,0,0,0],
    "y": [3.1, 5.2, 7.0, 9.1, 2.0, 3.8, 5.5, 7.2],
    "n_estimators": 100,
    "n_bootstrap": 50
  }'
```

### Example: Association Rule Mining

```bash
curl -X POST http://localhost:8020/analysis/rules \
  -H "Content-Type: application/json" \
  -d '{
    "prescriptions": [
      ["ST36", "LI4", "SP6"],
      ["ST36", "LI4", "LR3"],
      ["ST36", "SP6", "KD3"],
      ["LI4", "LR3", "GB34"],
      ["ST36", "LI4", "SP6", "LR3"]
    ],
    "min_support": 0.01,
    "min_confidence": 0.1,
    "min_lift": 1.0
  }'
```

## Methodology

### Target Trial Emulation

The system emulates a target randomized trial from observational data by:
1. Defining time zero (treatment initiation point)
2. Applying eligibility criteria to filter patients based on configurable rules (age range, baseline scores, etc.)
3. Specifying treatment and control arm definitions
4. Setting primary outcome measures and follow-up windows

### Causal Forest (T-Learner)

The causal forest estimates individualized treatment effects by:
1. Fitting separate Random Forest regressors on treated and control groups
2. Computing ITE as the difference in predicted outcomes: `ITE = Y(1) - Y(0)`
3. Generating bootstrap confidence intervals for both ITE and ATE estimates

### Uplift Modeling

The Two-Model uplift estimator:
1. Supports gradient-boosted trees (GBM) or Random Forest as base learners
2. Provides Qini curve evaluation for treatment targeting effectiveness
3. Identifies patients who benefit most from acupuncture treatment

### Association Rule Mining

The acupoint combination miner:
1. Discovers frequent itemsets (pairs, triples, k-itemsets) from prescription data
2. Generates association rules with support, confidence, and lift metrics
3. Reveals co-prescription patterns and acupoint synergies

## Research

This project is a **methodological prototype** that demonstrates how causal inference techniques could be applied to acupuncture data. Current work uses synthetic data to validate the pipeline; it does **not** make clinical claims. The framework is designed to support future research in:

- Evidence-based acupuncture through causal inference methodology
- Heterogeneous treatment effect estimation for personalized medicine
- Acupoint combination optimization using data-driven approaches
- Bridging observational TCM clinical data with rigorous statistical analysis
